# Pratiksha Pendse — Portfolio

This folder is ready to publish as a static GitHub Pages site.

## Update an existing portfolio

The October 2026 update adds the Microcontrollers section at the top of Projects and replaces the downloadable CV with the latest uploaded version.

Copy `projects.html`, `site.css`, and `assets/Pratiksha-Pendse-CV.pdf` into the existing `Portfolio` repository, keeping these paths. Then commit and push to `main`; the current GitHub Pages configuration will publish the changes.

## GitHub Pages

1. Create or open a GitHub repository.
2. Upload everything in this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main`, and select `/ (root)`.
5. Save and wait for GitHub Pages to publish the site.

The entry page is `index.html`. The other pages and the `assets` folder must stay beside it.
